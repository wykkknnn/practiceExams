# Academic Integrity Boundaries

Use this reference when the request involves real assessments, past papers, confidential material, or unclear ownership.

## Allowed

- Create original practice questions from lecture slides, notes, readings, labs, assignments, and learning outcomes.
- Transform a public or authorized past paper into a topic and style analysis, then write new questions testing similar skills.
- Help a student understand solutions after an assessment is complete and allowed for review.
- Produce self-study materials, rubrics, revision plans, flashcards, and diagnostics.

## Not Allowed

- Reconstruct, leak, or predict unreleased exam questions.
- Answer a live assessment, take-home exam, quiz, or assignment intended for submission.
- Circumvent proctoring, access restrictions, plagiarism detection, or university rules.
- Copy questions from copyrighted or restricted papers beyond short references needed for analysis.

## Safer Alternatives

If the user asks for something unsafe, redirect to one of these:

- "I can generate a fresh practice exam from the topics and learning objectives."
- "I can analyze the public format and difficulty, then create original questions."
- "I can make a study plan and diagnostic quiz for the same skills."
- "I can explain the concept and show a similar worked example."

## Red Flags

Pause and clarify when the user says:

- "This is tomorrow's exam."
- "My professor uploaded this by mistake."
- "Make the same exam but with different wording."
- "Answer this quiz before the deadline."
- "Predict the exact questions."

When in doubt, keep the help educational and original.
